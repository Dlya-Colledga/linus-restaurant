# LINUS — сайт ресторана (KY / RU / EN)

Учебный проект на HTML, CSS и Vanilla JavaScript. Никаких React, сборщика и обязательных npm-зависимостей. Данные ресторанов и меню демонстрационные.

## Запуск

Из папки с `index.html` запустите локальный сервер:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/`.

Открывать отдельные HTML через `file://` не рекомендуется: для некоторых браузерных функций и загрузки внешних ресурсов нужен HTTP-сервер.

## Структура

```text
index.html
menu.html
order.html
assets/
  css/
    shared.css
    index.css
    menu.css
    order.css
  data/
    translations.js
    branches.js
    menu.js
  js/
    core/
      i18n.js
      site.js
    index.js
    menu.js
    order.js
```

- `index.html` — выбор ресторана через колесо с прямым свайпом и клавишами-стрелками.
- `menu.html` — карусель категорий, DomeGallery, карточка блюда, корзина, Slide Commit.
- `order.html` — номер заказа, ThoughtLine, 5 этапов по 5 секунд, финальный экран с Particles и случайным кодовым словом.
- `shared.css` и `site.js` — компактный footer, языковой переключатель и окно с демонстрационными реквизитами.
- `translations.js` — словарь языков: русский (ru), кыргызский (ky), английский (en).
- `i18n.js` — применение переводов и сохранение выбранного языка.
- `branches.js` — адреса, изображения-заглушки, режимы работы, популярные блюда филиалов.
- `menu.js` в папке `data` — блюда, цены, описания, ингредиенты и аллергены (демонстрационные).
- `assets/js/menu.js` — механика карусели, 3D-сферы, модалки и оформления заказа.

## Языки

Переключатель KY / RU / EN находится в шапке каждой страницы. Начальный язык — русский, затем используется выбор пользователя из `localStorage` (`linus.language`). При переключении изменяются заголовки, кнопки, сообщения, категории, описания блюд, составы, статусы приготовления и реквизиты. Названия фирменных блюд остаются собственными именами бренда.

Новые переводы добавляйте в `assets/data/translations.js`. Элементы статической разметки переводятся через `data-i18n` / `data-i18n-aria`. Для динамических данных используется `LinusI18n.t()`.

## Хранение заказов

- `linus.selectedRestaurant` — выбранный филиал.
- `linus.cart.<branch-id>` — корзина соответствующего филиала.
- `linus.orders.v1` — история заказов текущего браузера.
- `linus.order.active` — номер активного заказа.
- `linus.language` — выбранный язык.

Это только локальное демонстрационное хранение. Настоящей оплаты, защищённой авторизации, интеграции с кухней и проверки кодовых слов на сервере нет. Перед реальным запуском эти процессы потребуют backend.

## Примечания к дизайну

Исходные стили и анимационные алгоритмы страниц меню и заказа сохранены. Внесены только компактный языковой контрол в шапку и минимальный footer снизу. Навигация по сайту рассчитана на один экран без вертикальной прокрутки страниц; длинная юридическая информация открывается в отдельном диалоге.

Сторонние изображения (Unsplash / placehold.co) и шрифты Google Fonts требуют интернета. В 3D-галерее предусмотрена локальная SVG-заглушка, если внешняя фотография не загрузится.
