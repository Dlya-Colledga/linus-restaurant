# LINUS · Vanilla + Vite

Курсовой проект ресторана в стилистике Linux. Три отдельных HTML entry points, ES-модули без React.

## Запуск

Требуется Node.js 20.19+ / 22.12+ и npm.

```bash
npm install
npm run dev
```

Откройте URL, который напечатает Vite. Страницы:

- `/` — выбор филиала;
- `/menu.html?location=asia-mall` — каталог с 3D-сферой, карточками и корзиной;
- `/order.html?id=XXXXXX` — история заказа и статус приготовления.

```bash
npm run build
npm run preview
```

`dist/` содержит три страницы и собранные Vite-ассеты. Публикуйте как статический сайт с сохранением путей HTML.

```text
index.html · menu.html · order.html

  core/

    site.js      — окно юридических данных
  data/

    menu.js      — блюда и свойства
    translations.js — словари
  pages/

    menu.js      — категории, 3D-сфера, модальная карточка, корзина и slide commit
    order.js     — CountUp, этапы приготовления, Particles
  styles/
    shared.css · index.css · menu.css · order.css
```

## Анимации

- **Общий переход карточки:** сама `.dish-panel` масштабируется и переносится из координат плитки на сфере к центру экрана; её покрытие постепенно открывает фото и описание. Закрытие — обратное преобразование, без переключения на отдельную летающую карточку.
- **Web Animations API (WAAPI):** открытие/закрытие блюда, появление текста, переходы фотографий и смена категорий, анимация номера и экрана готового заказа.
- **requestAnimationFrame:** только непрерывная физика свайпа и инерции глобуса, положение wheel, а также частицы на canvas — здесь анимация зависит от входных координат и времени между кадрами.
- Поддержка `prefers-reduced-motion`, блокировка глобуса на всё время открытой карточки.
- GSAP не требуется: native WAAPI обеспечивает FLIP-переход без дополнительного runtime-зависимого пакета.

## Данные и состояние

- `linus.language` — выбранный язык;
- `linus.selectedRestaurant` — филиал;
- `linus.cart.<branch-id>` — корзина для филиала;
- `linus.orders.v1` — заказы;
- `linus.order.active` — последний заказ.

Демо-заказ переключает 5 этапов по 5 секунд и переходит к экрану выдачи с сохранённым случайным Linux-словом. Серверных заказов, платежей и передачи на кухню пока нет.

Демонстрационные цены, графики, ингредиенты, адреса, реквизиты и электронная почта `support@linus-example.com` не предназначены для реального заведения. Фото блюд запрашиваются у Unsplash, некоторые внешние картинки могут быть недоступны.

## Где менять содержимое

- Названия, адреса, часы и фото филиалов — `src/data/branches.js`.
- Категории, блюда, цены и состав — `src/data/menu.js`.
- Кыргызский и английский переводы — `src/data/translations.js`.
- Скорость инерции — `DOME_SETTINGS` в `src/pages/menu.js`.
- Продолжительность открытия/закрытия карточки — `openDish` и `closeDish` в `src/pages/menu.js`.
